# Final Report Workspace

Use this folder for non-sensitive drafts and a delivery checklist only.

## Pre-submission checklist

- [ ] Executive summary explains priority risks and decisions required.
- [ ] Findings link clearly to anonymised evidence IDs.
- [ ] Risk ratings and treatment decisions are justified.
- [ ] Recommendations state cost, sequencing, ownership, and trade-offs.
- [ ] Literature is integrated into the analysis.
- [ ] Limitations, ethics, privacy, and compliance considerations are addressed.
- [ ] References and submission format have been checked.
- [ ] No original evidence, raw logs, credentials, personal data, or sensitive technical details are included.
