# CP5603 Assessment 2 — Cybersecurity Risk Assessment

This directory contains the public-safe working structure for Assessment 2. It holds anonymised analysis, templates, research notes, drafts and delivery tracking; the original Evidence Pack remains outside this public repository.

## Public-repository rule

Do **not** upload original evidence packs, raw logs, authentication records, screenshots containing personal data, credentials, IP addresses, student information, incident tickets, or other sensitive material.

Use anonymised summaries, synthetic examples and evidence IDs only. Keep original evidence in an approved private location.

## Structure and current artefacts

- 01_Assignment_Requirements — workflow, rubric mapping and quality checks
- 02_Evidence_Inventory — anonymised evidence inventory and master matrix
- 03_Evidence_Analysis — issue analysis, cross-reference matrix and conceptual topology
- 04_Risk_Assessment — risk register, prioritisation and ACS ethics log
- 05_Academic_Research — literature matrix, risk-intelligence log and external-draft audit
- 06_Innovation_Design — improvement-option template
- 07_Final_Report — [Part A](07_Final_Report/PartA_First_Draft.md), [Part B](07_Final_Report/PartB_First_Draft.md) and [Part C](07_Final_Report/PartC_Executive_Brief_Draft.md) drafts with delivery status pages

## Delivery position

All three parts have working drafts. They remain **in progress** until checked against the official task wording, marking criteria, word limit, citation requirements and final presentation rules.
